1. Questionário de Arquitetura

O sistema atual é monolítico ou modular?
HÍBRIDO MODULAR
Backend: Aplicação Spring Boot monolítica com organização interna modular por domínios
Frontend: Aplicação Next.js separada comunicando via REST API
Já usa Spring Boot?
SIM
Versão: Spring Boot 3.2.2 com Java 21
Componentes: Web, Security, Data JPA, Quartz, Cache, Actuator, WebFlux
Já existe autenticação JWT?
SIM
Biblioteca: JJWT 0.12.3
Access tokens (15 min) + Refresh tokens (7 dias)
Blacklist de tokens para logout | Claims: userId, role, plan, name
O banco é PostgreSQL?
SIM
Driver PostgreSQL com HikariCP (Connection Pool)
Migrações: Flyway 10.7.1 | ORM: Hibernate/JPA
Existe separação por módulos/domínios?
SIM - FORTE SEPARAÇÃO
Domínios: Agendamento, Profissional, Serviço, Cliente, Post, Pagamento, Imagem, WhatsApp, Métricas
O frontend é Angular ou React?
REACT (Next.js)
Next.js 16.1.6 | React 19.2.3 | TypeScript 5
Tailwind CSS 4 | Zustand | React Query | PWA habilitado
O sistema atual é SaaS multi-tenant ou single-tenant?
MULTI-TENANT (por Salão)
Cada usuário ADMIN possui um Salão (1:1)
Isolamento de dados por salon_id em todas as entidades
